# Security policy

This project is currently a developer preview, without a stable supported release. Please report suspected vulnerabilities privately via GitHub's **Report a vulnerability** mechanism, if enabled, or contact the maintainer privately before public disclosure. Do not paste secrets, tokens, or private session details into issues.

The plugin connects to a local OpenDeck WebSocket and Hyprland IPC and invokes `hyprctl`. Installation should never require running arbitrary commands obtained from issue comments.
