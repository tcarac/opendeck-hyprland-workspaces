# Contributing

Issues and pull requests are welcome. Start with `npm install && npm test`. Use a focused branch and complete the PR template. Maintainers review all contributions, including AI-assisted contributions. Disclose material AI assistance when useful, and verify all generated code and dependency changes. No auto-merge is configured.

## Compatibility reports
Include OS/Omarchy version, Hyprland dispatcher type, OpenDeck version and installation method, exact controller model, and redacted plugin logs.

## Security
For vulnerabilities, do not open a public issue; see SECURITY.md.
